# Барбершоп №1 — сайт барбершопа (демо)

Одностраничный сайт для вымышленного барбершопа: hero, прайс, мастера, галерея, онлайн-запись, отзывы, контакты. Чистые HTML, CSS и JavaScript, без фреймворков и сборки. Адаптивный, с мобильным меню.

**Онлайн-запись (демо):** выбор услуги, мастера, даты и времени (занятые слоты показываются условно), проверка имени и телефона, итоговая сводка. Данные никуда не отправляются.

A demo one-page website for a fictional barbershop: services and prices, team, gallery, an online booking form (client-side only), reviews and contacts. Plain HTML, CSS and JavaScript, fully responsive.

## Как открыть
Откройте `index.html` в браузере.

## Что менять под реального клиента
Все данные в начале `script.js`: услуги и цены (`SERVICES`), мастера (`MASTERS`), фото (`PHOTOS`), часы работы (`OPEN`). Адрес, телефон и название меняются в `index.html`.

Чтобы форма записи реально работала, её нужно подключить к серверу или сервису (например, Formspree, Google Forms или Telegram-бот). В демо этого нет.
